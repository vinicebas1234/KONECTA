🏗️ Arquitetura Multi-IA

Cada IA tem um propósito estratégico no pipeline:

🤖 IA 📋 Responsabilidade ⏱️ Latência 🎯 Quando Usar
KONECTA V3 Classificação rápida (RF/MLP) 100-150ms SEMPRE
Claude Validação contextual + Lógica 200-500ms Confidence 0.7-0.85
Gemini Vision Análise de landmarks 200-300ms Paralelo (valida qualidade)
Grok Histórico e contexto 300-1000ms Confidence < 0.7
Codex Otimizações dinâmicas N/A (Background) Melhoria contínua

🔄 Fluxo do Pipeline

📹 Estágio 1: Captura

Câmera captura vídeo em tempo real (30fps, 640x480)

⏱️ 0-33ms

⚡ Estágio 2: Reconhecimento Paralelo

KONECTA V3 + Gemini Vision processam simultaneamente

⏱️ 100-300ms

🎯 Estágio 3: Decisão por Confiança

Confidence > 0.85: ✅ Resultado imediato
0.7-0.85: ⚠️ Claude Logic valida
< 0.7: 🔍 Grok Context enriquece

⏱️ 0-1000ms

💾 Estágio 4: Cache + Output

Armazena resultado e notifica N8N assincronamente

⏱️ 5-100ms (async)

✅ Resultado Final

Sinal reconhecido pronto para uso na aplicação

⏱️ 300-1200ms total

🔗 Integração com N8N

KONECTA Intelligence Hub envia webhooks para N8N com este formato:

{ "signal": "OLHO", "confidence": 0.98, "latency_ms": 234, "confidence_level": "high", "validated_by": "ensemble", "recommendation": "accept", "timestamp": "2026-08-11T15:30:45.123Z", "user_id": "user_123" }

🔄 Como funciona:
1. KONECTA reconhece sinal → 300-1200ms
2. Envia webhook para N8N (assincronamente)
3. N8N chama seus motores (Speech-to-Text, Text-to-Sign)
4. N8N retorna para frontend com tudo integrado

⚡ Importante: Webhooks são assincronos, não bloqueiam a UI!
