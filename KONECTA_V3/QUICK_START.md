# ⚡ QUICK START - KONECTA V3

## 🚀 Iniciar Tudo

**Duplo clique em:**
```
start_all.bat
```

Isso vai abrir:
- ✅ **Backend** (FastAPI na porta 8000)
- ✅ **Frontend** (GUI Tkinter)

Pronto! Aguarde as janelas abrirem.

---

## 🛑 Parar Tudo

**Duplo clique em:**
```
stop_all.bat
```

Fecha todas as janelas automaticamente.

---

## 📋 Alternativas Manuais

Se preferir rodar no CMD:

**Backend:**
```bash
python vision_lab/app.py
```

**Frontend:**
```bash
python app_gui_v2.py
```

| Componente | Endereço |

## ⚙️ Requisitos

- Python 3.9+ instalado
- Dependências instaladas: `pip install -r requirements.txt`
- Câmera conectada (para GUI)
- Windows (os bats são .bat)

---

**Dúvidas?** Rode `python teste_rapido.py` para teste rápido sem GUI.
